# 配置别名输入框优化

## 更新日期
2025-10-30

## 更新内容

优化配置管理界面，使用独立的别名输入框来保存配置，使操作更加灵活直观。

## 主要改进

### 1. 界面调整

**移除：**
- ❌ "新建配置"按钮

**新增：**
- ✅ "配置别名"输入框（在选择配置下方）

**调整：**
- ✅ "删除配置"按钮移到"保存当前配置"旁边

### 2. 操作流程优化

**保存配置：**
- 在"配置别名"输入框输入名称
- 点击"保存当前配置"
- 自动保存到该别名下

**加载配置：**
- 在"选择配置"下拉框选择
- 自动加载配置
- 别名输入框自动同步

## 使用方法

### 1. 创建新配置

```
1. 在"配置别名"输入框输入新名称
   例如: binance-eth
   
2. 填写交易所、API 密钥等参数

3. 点击"💾 保存当前配置"

4. 配置保存成功
   - 下拉框自动更新
   - 自动选中新配置
```

### 2. 修改现有配置

```
1. 在"选择配置"下拉框选择配置
   - 配置自动加载
   - 别名输入框自动同步

2. 修改参数

3. 点击"💾 保存当前配置"
   - 覆盖原配置
```

### 3. 另存为新配置

```
1. 在"选择配置"下拉框选择配置
   - 配置自动加载

2. 修改"配置别名"为新名称
   例如: binance-eth-aggressive

3. 修改参数

4. 点击"💾 保存当前配置"
   - 创建新配置
   - 原配置不变
```

### 4. 删除配置

```
1. 在"配置别名"输入框确认要删除的配置名称

2. 点击"🗑️ 删除配置"

3. 确认删除

4. 配置被删除
   - 下拉框更新
   - 自动切换到 default
```

## 功能特点

### 1. 灵活保存

**输入新别名：**
- 创建新配置
- 不影响现有配置

**使用现有别名：**
- 覆盖该配置
- 更新配置内容

### 2. 自动同步

**选择配置时：**
- 下拉框选择配置
- 别名输入框自动同步
- 配置参数自动加载

**保存配置后：**
- 下拉框自动更新
- 自动选中保存的配置

### 3. 操作直观

- 输入框清晰显示当前要保存的别名
- 可以随时修改别名
- 支持另存为操作

## 技术实现

### 下拉框改变时同步

```javascript
function onConfigSelectChange() {
  const config_name = document.getElementById("configSelect").value;
  // 同步别名输入框
  document.getElementById("configAlias").value = config_name;
  // 加载配置
  loadConfigByName(config_name);
}
```

### 保存时使用别名输入框

```javascript
function saveConfig() {
  const config_name = document.getElementById("configAlias").value.trim();
  // 保存到该别名
  fetch("/api/config/save", {
    body: JSON.stringify({ config, config_name })
  });
}
```

### 保存后同步下拉框

```javascript
.then(data => {
  if (data.success) {
    updateConfigSelect(); // 更新下拉框
    setTimeout(() => {
      // 选中刚保存的配置
      document.getElementById("configSelect").value = config_name;
    }, 100);
  }
});
```
