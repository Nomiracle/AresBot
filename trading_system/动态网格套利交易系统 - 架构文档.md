## 📋 项目概述
**项目名称**: 动态网格套利交易系统  
**版本**: 2.0 (重构版)  
**技术栈**: Python 3.8+, WebSocket, Threading  
**核心模式**: 状态机 + 命令模式 + 事件驱动

## 🔄 核心流程
### 3. 状态机转换图
```puml
@startuml
[*] --> PENDING : 创建订单

PENDING --> PLACED : 下单成功
PENDING --> FAILED : 下单失败

PLACED --> FILLED : 订单成交
PLACED --> CANCELLED : 订单取消
PLACED --> REPRICING : 开始改价
PLACED --> FAILED : 异常

REPRICING --> PLACED : 改价完成
REPRICING --> CANCELLED : 改价时取消
REPRICING --> FAILED : 改价失败

FILLED --> [*] : 终态
CANCELLED --> [*] : 终态
FAILED --> [*] : 终态

note right of PLACED
  活跃状态
  可以改价
end note

note right of REPRICING
  临时状态
  正在改价中
end note

note right of FILLED
  终态
  订单完成
end note

@enduml
```

### 4. 主循环序列图
```puml
@startuml
actor User
participant Orchestrator
participant Context
participant OrderManager
participant Executor
participant Exchange
participant EventBus

User -> Orchestrator : start()
activate Orchestrator

Orchestrator -> Orchestrator : _initialize()
Orchestrator -> Exchange : get_trading_rules()
Exchange --> Orchestrator : rules

Orchestrator -> Exchange : start_ws(on_price, on_order)
Exchange --> Orchestrator : connected

loop 主循环 (每N秒)
    Orchestrator -> Context : get_current_price()
    Context --> Orchestrator : price
    
    alt 价格有效
        Orchestrator -> Exchange : get_open_orders()
        Exchange --> Orchestrator : open_orders
        
        Orchestrator -> Orchestrator : _adjust_grid()
        note right: 取消超范围订单
        
        Orchestrator -> Orchestrator : _reprice_orders()
        note right: 改价未成交订单
        
        Orchestrator -> Context : needs_more_orders()
        Context --> Orchestrator : true/false
        
        alt 需要补单
            Orchestrator -> Executor : execute(PlaceBuyOrderCommand)
            Executor -> Exchange : order_limit_buy()
            Exchange --> Executor : order_result
            Executor -> OrderManager : add_order()
        end
    end
end

== 异步事件处理 ==

Exchange -> EventBus : publish('order_filled', event)
EventBus -> Orchestrator : _on_order_filled(event)
Orchestrator -> Orchestrator : _handle_buy_filled()
Orchestrator -> Executor : execute(PlaceSellOrderCommand)
Executor -> Exchange : order_limit_sell()

deactivate Orchestrator

@enduml
```

### 5. 买单成交流程
```puml
@startuml
|WebSocket线程|
start
:收到订单成交事件;

if (是否为本交易对?) then (否)
  stop
endif

:发布到事件总线;

|主线程|
:事件总线触发回调;
:_on_order_filled();

if (订单已处理?) then (是)
  stop
endif

:标记订单已处理;
:设置禁止下单标志;

if (是买单?) then (是)
  :获取成交信息;
  :计算实际数量;
  note right
    扣除手续费
    对齐到交易规则
  end note
  
  :更新买单状态 -> FILLED;
  :发送买入通知;
  
  :计算卖出价格;
  note right
    使用价格策略
    支持衰减逻辑
  end note
  
  :创建PlaceSellOrderCommand;
  :执行挂卖单;
  
  if (挂单成功?) then (是)
    :创建卖单状态机;
    :添加到OrderManager;
  else (失败)
    :记录错误;
  endif
else (卖单)
  :更新卖单状态 -> FILLED;
  :计算盈亏;
  :发送卖出通知;
endif

:清除禁止下单标志;
stop

@enduml
```

### 6. 改价流程
```puml
@startuml
|主循环|
start
:获取活跃订单列表;

fork
  :遍历买单;
  while (有下一个买单?) is (是)
    :创建RepriceBuyOrderCommand;
    
    if (可以改价?) then (是)
      :计算新价格;
      
      if (价格差异足够?) then (是)
        :状态转换 -> REPRICING;
        :调用交易所改价API;
        
        if (改价成功?) then (是)
          :更新订单价格;
          :状态转换 -> PLACED;
        else (失败)
          :状态恢复 -> PLACED;
          :记录错误;
        endif
      else (差异过小)
        :跳过改价;
      endif
    else (状态不允许)
      :跳过;
    endif
  endwhile (否)
fork again
  :遍历卖单;
  while (有下一个卖单?) is (是)
    :创建RepriceSellOrderCommand;
    :执行改价逻辑;
    note right: 同买单流程
  endwhile (否)
end fork

stop

@enduml
```

## 📝 使用示例
### 启动交易
```python
# 创建配置
config = TradingConfig(
    symbol="BTCUSDT",
    exchange="binance",
    quantity=0.01,
    interval=1,
    order_grid=3,
    offset_percent=-0.1,
    sell_offset_percent=0.5
)

# 创建上下文
context = TradingContext(
    username="trader1",
    user_id="uid123",
    config=config,
    exchange=exchange_adapter
)

# 启动编排器
orchestrator = TradingLoopOrchestrator(context)
orchestrator.run()
```

### 查询状态
```python
# 获取活跃订单
active_buys = context.get_active_buy_orders()
active_sells = context.get_active_sell_orders()

# 检查是否可以下单
can_place, reason = context.can_place_order()

# 查看市场状态
current_price = context.market.current_price
target_price = context.market.target_price
```
